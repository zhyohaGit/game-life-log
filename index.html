备份与导入

所有数据只在本地处理。建议偶尔导出 JSON 备份，换浏览器或换电脑时再导入。

导入 JSON 备份

选择之前导出的 JSON 文件，会覆盖当前本地记录。初始种子数据不会被改写。

生成发布文件

把浏览器里的本地记录导出成仓库可提交的 data.json 和 data.js。网页发布时用这两份文件作为正式数据。

一键保存并发布

用 `start-local.ps1` 打开的本地版可以直接把当前记录写回仓库并推送到网页。

本地发布助手连接后即可使用。

恢复初始数据

清空浏览器里的本地修改，回到 data.js 里的初始记录。操作前建议先备份 JSON。

粘贴 CSV 快速导入

支持字段：date, platform, device, title, status, hours, note, memory, tags, steamAppId, cover, coverPosition, spoiler, spoilerNote。

CSV 会追加到当前记录。
